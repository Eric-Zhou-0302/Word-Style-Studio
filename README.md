# 字序 · Word 样式工作室

**把格式设好，让写作更专注。**

字序让你在浏览器中整理 Word 的字体、段落、表格与编号规则，再导出一份带有这些样式的空白文档或模板。在 Word 中写作时，直接应用样式即可复用格式，不必每次从头设置。

![字序工作区](public/images/workspace-preview.png)

## 可以用它做什么

- **建立自己的样式库**：设置标题、正文、题注和表格文字，管理样式继承与快速样式。
- **理清编号规则**：创建项目符号、编号列表和最多九级的多级列表，让标题与编号关联。
- **统一表格格式**：设置边框、底纹、单元格文字，以及表头、末行和条带等区域。
- **制作可复用模板**：配置页面尺寸、页边距，导出 DOCX 文档或 DOTX 模板。
- **保存自己的方案**：在浏览器中继续编辑，也可用 JSON 备份或迁移到另一台设备。

无需注册账号。文档解析和导出在浏览器本地完成，不会上传文档内容。

## 从哪里开始

进入首页后，可以选择：

| 入口 | 适合什么情况 |
| --- | --- |
| 进入工作区 / 继续编辑 | 开始使用，或接着修改当前浏览器保存的方案 |
| 从示例开始 | 在一套完整的报告格式上调整 |
| 从空白开始 | 从基础正文样式开始，逐步建立自己的规则 |

示例方案包含 **29 个独立样式和 3 套列表**，覆盖报告标题、目录条目、六级标题、正文、图表说明和表格格式。各样式不互相继承，适合作为起点再按需修改。

新建方案会替换当前方案，操作前会提示确认。已有重要设置时，建议先下载 JSON 备份。

### 三步做出自己的 Word 模板

1. **设置格式**：在左侧选择样式或列表，调整字体、段落、编号和页面。想让整张表格居中，请设置“整张表格对齐”；“单元格段落”控制的是表格内的文字。
2. **检查效果**：查看实时预览和编号测试。首次导出时建议勾选“包含样式示例”，在 Word 中检查实际效果。
3. **开始写作**：确认后关闭示例，导出空白文档或模板，在 Word 中应用已建立的样式。

更详细的说明、样式基础知识和操作示例，可从首页“使用文档”或工作区左侧“使用说明”查看。

## 导出哪种文件

| 格式 | 用途 |
| --- | --- |
| **DOCX** | 打开后直接写作；默认正文为空，样式和列表规则已保留 |
| **DOTX** | 作为模板，用来创建多份格式一致的新文档 |
| **JSON** | 保存完整的网页方案，方便备份、恢复和换设备继续编辑 |

也可以导入已有的 JSON、DOCX 或 DOTX。外部 Word 文件只提取支持的样式、列表和页面设置，不导入正文，也不能完整还原全部 Word 功能；导入前会显示说明。

**注意：**本工具导出的 Word 文件带有内嵌方案，重新导入时会优先恢复这份方案。在 Word 中修改样式后，内嵌方案不会同步更新，回导可能恢复较早的网页设置。请保留原文件，并留意导入提示。

## 使用前了解这些

- **字序用于设置格式与模板。** 正文写作在 Word 中完成；目录样式不会自动生成目录，脚注样式也不会自动插入脚注。
- **网页预览是参考。** 分页、字体、制表位等效果可能与 Word 不同，重要文档请在实际使用的 Word 中检查。设备上也需要安装相应字体。
- **自动保存只在当前浏览器。** 更换设备、浏览器或网站地址不会自动同步；清理浏览器数据前，请下载 JSON 备份。
- **撤销仅在当前页面会话有效。** 关闭或刷新页面后，不能依靠原来的撤销历史恢复修改。

## 在自己的电脑上使用

目前可以下载本仓库，在安装了 **Node.js 24** 的电脑上进入项目目录，执行：

```sh
npm ci
npm run dev
```

然后打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。
