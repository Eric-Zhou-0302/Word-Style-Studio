# 字序 Word 样式工作室

**把报告排版规范做成可复用的 Word 模板。**

在浏览器中配置标题、正文、图表、表格与自动编号，导出保留原生样式和动态编号的 DOCX 文档或 DOTX 模板。字序负责样式与模板设计，正文写作在 Word 中完成。

文件解析与导出均在浏览器本地执行，无需上传文档、注册账号或配置后端。方案自动保存在当前浏览器，也可下载 JSON 备份。

## 开始使用

使用 **Node.js 24.x 和 npm**，在项目目录中执行：

```sh
npm ci
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。开发端口固定为 5173；已使用 nvm 的开发者可先运行 `nvm use`。

1. **配置方案**：在首页进入工作区，或选择从示例、空白开始；从报告方案开始，选择样式或列表，调整字体、段落、表格与编号；也可导入 JSON、DOCX 或 DOTX。
2. **检查效果**：查看即时预览与“编号测试”，再点击“导出 Word”，开启“包含样式示例”，在 Microsoft Word 中验收。
3. **保存并使用**：确认后关闭示例，导出空白 DOCX 或 DOTX 模板，并另存一份 JSON，便于继续修改或迁移设备。

完整操作指南可从首页“使用文档”或工作区左侧“使用说明”进入，本地可直接打开 [使用说明](http://127.0.0.1:5173/#guide)。

## 可以配置什么

| 功能 | 支持范围 |
| --- | --- |
| 样式 | 段落、字符、链接与表格四类样式；新建、复制、删除、重命名、继承、后续段落、快速样式与显示顺序 |
| 字体与段落 | 中西文字体、字号、字符间距、缩放、文字效果；对齐、缩进、行距、分页控制、制表位、边框与底纹 |
| 列表与编号 | 项目符号、单级编号、九级多级列表；上级引用、起始值、重启规则、法律编号、图片项目符号；段落或链接样式与层级双向绑定 |
| 表格与页面 | 整表及十二种条件区域格式、四边单元格内边距；A4/A5/Letter、横纵方向、页边距与页眉页脚距离 |
| 编辑与预览 | 即时样式预览、报告场景预览、编号序列测试、窄屏布局、撤销重做、本地自动保存 |

每个方案最多包含 200 个样式、30 套列表。空白导出默认不带示例文字；样式、列表规则和页面设置保留在文件中。

## 默认报告方案

“从示例新建”内置 **29 个独立的报告专用样式**。其中 28 个专用段落样式覆盖封面、目录条目、六级标题、正文、图表说明和表格文字，另有 1 个“标准表格”样式。标准表格不继承其他表格样式，默认不含 Normal Table。

三套列表分别用于六级标题、两级正文编号和正文项目符号。页面为 A4 纵向，上下页边距 2.75 cm、左右 2.5 cm；中文使用宋体、黑体或楷体，西文与数字默认继承 Times New Roman。字体需在使用设备上安装。目录样式只提供格式，**不会自动生成目录域**。

旧浏览器存档不会被新版默认方案替换。如需载入当前默认配置，请先备份，再从“方案管理”选择“从示例新建”。

“从空白新建”仅保留正文（Normal），不含列表，并恢复基础字体、段落和页面设置；左侧“清空样式与列表”则保留当前正文格式、名称和页面设置；没有 Normal 时会创建基础正文。

## 文件与数据保存

| 文件 | 用途 |
| --- | --- |
| DOCX | 带有样式与列表定义的 Word 文档，打开后继续写作；可选空白正文或验收示例 |
| DOTX | 原生 Word 模板，用于创建多份新文档；同样可选是否包含示例 |
| JSON | 完整可编辑方案，用于备份、换设备与恢复设置，不包含报告正文 |

**外部 Word 导入是有损提取。** 仅提取支持的样式、列表与页面设置，不保留正文、页眉页脚内容、批注、修订、宏、外部图片项目符号或全部未知属性。导入前会显示报告，确认后替换当前方案，可通过撤销恢复。输入文件上限为 10 MB，Word 文件解压后上限为 40 MB；支持 `.docx`、`.dotx` 与方案 `.json`，不支持加密文件。

本应用导出的 Word 文件会嵌入方案 JSON，回导时优先恢复该方案。**在 Word 中修改样式不会更新内嵌方案**，回导可能恢复原来的网页设置；请阅读导入报告并保留原文件。

本地存储按站点地址隔离，不会跨浏览器、设备或域名同步。清理浏览器数据或更换地址前，请导出 JSON；撤销历史只在当前页面会话中保留。文档本地处理不意味着访问网页时没有资源请求。

## 预览与兼容性

网页预览帮助检查设置，**不等同于 Word 排版引擎**。表格预览支持条件区域继承、边框、条带大小及区域开关，编号测试支持全部九级与自定义序列。预览仍不模拟完整分页和页眉页脚区域，共享边框冲突、制表位与高级字体效果也可能不同。最终文件应在实际使用的 Word 客户端验收，快速样式与列表画廊的显示受客户端设置影响。

外部 Word 导入的“自动更新”标记读取问题已修复。修复记录及其他边界见 [使用文档与实际行为审计](docs/guide-audit.md)。主题字体动态切换、格式限制、全部语言编号及文档网格尺寸编辑等尚未完整覆盖，目标清单见 [PLAN.md](PLAN.md)。

## 开发与部署

项目采用 React、TypeScript 和 Vite，以 Zod 校验方案、fflate 处理压缩包。纯客户端运行，无需数据库、API 密钥或应用环境变量。依赖以 `package-lock.json` 为准，`.nvmrc`、CI 与 Vercel 统一以 Node.js 24 为目标。

```sh
npm test
npm run build
```

构建先执行 TypeScript 检查，再生成 `dist/` 静态文件；可用 `npm run preview` 本地检查构建结果。

| 入口 | 职责 |
| --- | --- |
| [src/model.ts](src/model.ts) | 方案结构、默认配置、校验、继承与引用规则 |
| [src/export.ts](src/export.ts) / [src/import.ts](src/import.ts) | OOXML 导出、外部 Word 提取与导入报告 |
| [src/numbering.ts](src/numbering.ts) | 编号格式与预览计数器 |
| [src/components/](src/components/) | 格式编辑器与预览 |
| [src/useProject.ts](src/useProject.ts) | 浏览器存储与撤销重做 |
| [src/Guide.tsx](src/Guide.tsx) / [tests/](tests/) | 应用内使用说明与自动化测试 |

开发约定见 [CONTRIBUTING.md](CONTRIBUTING.md) 与 [AGENTS.md](AGENTS.md)。界面改动需要浏览器操作验证；导出改动需要 OOXML 检查与 Microsoft Word 实测。

[GitHub CI](.github/workflows/ci.yml) 执行安装、测试和构建；[Vercel 配置](vercel.json) 在构建前运行测试。首次建仓及发布步骤见 [GitHub 发布准备](docs/github-release.md)，上线步骤见 [Vercel 部署](docs/deployment.md)。配置文件不代表远端检查或部署已经执行。

更新记录见 [CHANGELOG.md](CHANGELOG.md)，安全反馈见 [SECURITY.md](SECURITY.md)。
